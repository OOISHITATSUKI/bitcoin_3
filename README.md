# Binance Trading Bot

Binance APIを使用した自動取引ボットアプリケーション

## 機能

- Binance APIとの接続
- リアルタイム価格監視
- 自動取引実行
- グリッドトレード戦略
- AI最適化
- パフォーマンス分析

## セットアップ

1. 必要な依存関係をインストール:
```bash
npm install
```

2. 環境変数の設定:
`.env`ファイルを作成し、必要な環境変数を設定:
```
REACT_APP_BINANCE_API_KEY=your_api_key
REACT_APP_BINANCE_API_SECRET=your_api_secret
```

3. アプリケーションの起動:
```bash
npm start
```

## 開発

- `npm test`: テストの実行
- `npm run build`: プロダクションビルドの作成
